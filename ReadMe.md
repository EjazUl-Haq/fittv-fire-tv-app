 # FitTV - Smart Home Fitness Dashboard (Fire TV Track)

## Overview
FitTV is a lightweight, web-based living room fitness dashboard built specifically for Amazon Fire TV / Vega OS environments[cite: 7]. It provides a clean, remote-friendly UI with quick workout categories and an interactive countdown timer.

## Track
- **Primary Track:** Fire TV[cite: 7]

## Features
- **TV-Optimized UI:** Designed with a clean light outer theme and high-contrast dark interactive cards/boxes.
- **Remote Navigation Support:** Focus states built explicitly for D-pad and remote control navigation simulation.
- **Interactive Timer:** Built-in JavaScript countdown timer for quick daily workout routines.

## Project Structure
- `index.html` - Main markup structure for the TV screen.
- `style.css` - Custom styling optimized for TV layouts and focus transitions.
- `script.js` - Interactive workout timer logic.

## How to Run Locally
1. Clone or download this repository to your local machine.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using a local server (like VS Code Live Preview) or test it inside a Fire TV web browser / Vega simulator[cite: 7].
